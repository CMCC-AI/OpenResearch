# MobileSci 0.2.23-mobilesci.3

完善研究材料从读取、声明到封存交付的来源链。此版包含 `.2` 之后的读取正确性、声明修订、持久回执、网页定位和交付快照；官方合并祖先仍是 v0.2.19，v0.2.23 为部分回移，官方自动更新保持关闭。

## 材料与证据

- 文本、Notebook 和 PDF 从核验后的字节快照读取；PDF 通过 stdin 解析，统一 30 秒超时，正文和诊断输出有界。
- 读取事件持久记录来源、选区、正文哈希、实际会话/任务/计划及输出状态。written 只证明 CLI 输出成功，不证明模型理解或独立审查。
- 声明支持撤回/替代并保留历史。materialReadId 解析为规范 materialCitation，限制当前计划材料集合并核验原件；新证据使旧审查和交付范围失效。
- 当前专家团的“证据与来源”页可查看当前/历史声明及原文选区，CLI locate 重新定位。网页查看是只读操作，不新增 Agent 阅读事实；只读案例不回退到私人实例。

## 封存交付

- 当前产物、选定 Run 日志、有效引用原件和对应回执随 ZIP 封存，包含路径/字节数/SHA-256 清单。哈希与复制在 SQLite 写事务外准备，提交与批准前复核输入和文件身份。
- 人工确认后提供科研专家团下载和 `orx research export > research.zip`；未批准、范围变化或包损坏时拒绝。已批准归档不随原件后续变化重建，已结束研究可下载仍有效的已确认包。
- 历史活动 Run 保护保留，旧未引用日志不重新扩入交付；归档不导出原始 backend 配置或未声明的整个工作目录。

## 工作台与模型接入

- 汇总已合入的模型连接验证/断开能力，沿用现有模型配置与账号边界。
- 统一工作台新会话入口替代旧版新对话页，保留 starter 和中性加载回退。

## 兼容、验收与部署边界

- 新增持久读取事件及来源/修订/快照兼容保护，使用这些功能的所有 CLI/执行器需同步升级。旧写入器不得丢弃新字段；旧记录不补造阅读事实。带材料引用的旧交付需重新申请/确认；无材料旧 scopeHash 保持兼容，ZIP 描述符独立存储并校验。
- 真实 Poppler 验收覆盖分页、越界页、损坏 PDF、无文本图片页、缺失工具与恢复后的回执定位；Linux 与 macOS CLI CI 强制执行，执行器离线自检也覆盖真实解析。测试使用合成资料，不代表 OCR、复杂版面或科研质量已完成验收。
- 单包最多 2,048 项、512 MiB 内容；单产物/引用原件沿用 32 MiB 限额。缓存全局配额、孤立包回收、阅读覆盖、解析器身份和科学指标来源仍待实施。
- 源码 tar.gz、zip、SHA256SUMS 与 source-release.json 仅在同一候选的完整 CI 成功后自动发布。本版不包含签名安装包或生产部署；现有实例不会因源码发布自动获得新 CLI、ui/dist 或 pdftotext。
