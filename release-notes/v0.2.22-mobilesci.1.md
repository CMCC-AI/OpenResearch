# MobileSci 0.2.22-mobilesci.1

本次发布冻结当前科研工作台、材料阅读与会话可靠性改进，提供固定版本的源码归档。后续技术债在此版本之后继续推进。

## 主要改进

- 研究工作区增加固定的“研究材料”入口，支持上传文件夹目录浏览、搜索、类型筛选、PDF／Markdown／文本／图片只读预览，以及多次导入的批次切换。
- 材料阅读保留来源编号、相对路径、导入版本和 SHA-256；浏览原件不会标记 AI 已读。不支持的格式提供下载入口，并兼容旧服务的原件下载接口。
- 改善模型冷启动就绪：在限定时间内等待插件激活，保持完整模型／集成目录，刷新失败时保留设置选择。
- 修复发送前历史查询被重连取消的竞争；本地发送失败独立显示，保留上一轮模型回答及草稿隔离。
- 普通发送及队列按持久请求回执核实丢回包结果，不再以会话 busy 状态推断本次请求成功；结果不确定时保留当前草稿和重试身份。
- 改善研究任务继承判断、存储争用、执行续租与停止收尾，并为执行器补充离线工具链及权限配置。
- 保留精选案例与个人项目各自的导航和操作入口。

## 发布内容与使用

Release 附件包含源码 `.tar.gz`、`.zip`、SHA-256 校验清单及版本／提交清单。Git 标签与归档绑定同一提交。

本地源码开发使用 `./start-mobilesci-dev.command`；构建版入口为 `./start-mobilesci.command`。私人托管版的配置、备份和升级步骤见仓库 `docs/product/runtime-and-deployment.md` 与 `docs/product/deploy-mobilesci.md`。

这是源码版本发布，不包含签名桌面安装包，也不代表线上服务已升级。部署时仍须执行对应环境的备份、升级与恢复验收。
