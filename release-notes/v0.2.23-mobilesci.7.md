# MobileSci 0.2.23-mobilesci.7

本版集中交付多用户私人工作台、月度 Token 额度和既有稳定性修补。真实官方合并祖先仍为 v0.2.19，v0.2.23 为部分回移；继承既有 v0.2.24 专项适配，并选择 v0.2.26 的两项聊天修补，不表示整版同步。官方自动更新保持关闭。

## 多用户与月度额度

- 注册默认每月 200 万 Token，管理员逐用户配置，按上海自然月重置、不结转；在途请求结算原账期，已有账户策略不因升级重置。
- 平台模型通过用户 runner 身份绑定的网关准入，保守预占上下文及最大输出，按可信实际用量幂等结算。仅明确未建立连接或供应商已拒绝的请求释放预占；连接中断、未知用量保留待确认。异常响应采用非自动重试状态，显示可追查请求标识。
- 上游 Key 不挂入用户执行器；旧配置须显式迁移，保留研究数据和备份。历史已导出 Key 无法由网关约束，确认使用范围后再考虑轮换；自带 Key、订阅及未接入协议不冒充已计量。
- 私人环境按需调度与闲置释放；注册不要求所有容器同时运行。保留用户独立 HOME、容量队列与非 root 工具权限，修正 OpenCode 缓存目录写权限。

## 设置、模型与聊天

- Token 额度位于个人二级菜单，账户资料与密码位于工作台设置；管理员从系统管理配置用户额度与补账。旧账号页负责认证及兼容跳转；个人设置不唤醒科研执行器，修改密码使旧会话失效。
- 模型选择器平铺当前可用模型，支持搜索与滚动；不承诺固定数量。模型及执行器设置统一入口，界面隐藏底层代理标识，保留必要运行集成。
- 按官方 #935 约束未决计划为当前用户轮次，历史计划不再阻塞追问；用户 Shell 执行保留当前审批。按 #922 稳定图片轮播组件，避免文本更新重置所选图片。
- 首条消息确认后再跳转，前端资源重新校验缓存并提示页面更新；文献来源统一 arXiv 显示。Agent 人设统一 MobileSci 身份和科研能力约束。

## 原生代码与升级边界

- 将研究计划继承的材料／产物哈希核验移出数据库写锁，在短事务内复核身份与审批失效条件；升级 SQLite 依赖以满足安全审计。
- 已有输入冻结能力保存独立副本并预约副本池容量，属于显式启用能力。冻结集合保留会限制项目删除，不能视为完整可复现环境或固定数据复跑闭环。PR #17 继续保留草稿，全后端追溯、环境封存、指标曲线与 ACP 扩展不纳入本版。
- 本版源码发行与服务器升级分别验收：同一候选必须通过完整 CI；原生 CLI／执行器须先在真实数据副本验证升级、读取与回退，再在空闲窗口统一部署。回退保留数据库，不覆盖科研成果。
- 发行提供源码 tar.gz、zip、SHA256SUMS 和 source-release.json；签名桌面包及自动更新通道不在本轮交付承诺内。部署状态及证据见[发布计划](../docs/product/release-v0.2.23-mobilesci.7-plan.md)。
