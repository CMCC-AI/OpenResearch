# MobileSci 0.2.23-mobilesci.4

为材料读取增加可观察的解析视图身份和任务范围汇总，提供有界容量观测，并消除源码归档的主机元数据差异。真实官方合并祖先仍为 v0.2.19，v0.2.23 仍是部分回移；本版包含 v0.2.24 的分析台账，没有宣称完整接入 .24，也不启用官方自动更新。

## 读取身份与范围

- 新回执记录完整文本/Notebook/单页 PDF 解析视图的哈希、解析方式/修订和 CLI 产品版本；PDF 另有界观察同一工具的报告版本与二进制哈希，执行前后核验文件身份。版本探测和正文解析共用原有期限，旧记录保留身份未知。
- `orx materials coverage --package <id>` 按实际任务、计划、包/SRC/原件、解析视图和页码合并已确认输出的范围；重复读取不重复计数，失败、pending、空/无效选区和未知身份分开报告。超过查询上限时要求缩小范围，不给部分总数。
- CLI 定位新回执额外复核完整视图与解析身份。CLI 版本仅为观测字段，相同解析身份/视图在升级后仍可定位，汇总另列生产者版本。规范引用、旧审批及旧回执定位兼容，网页只读回放不产生 Agent 阅读记录。本版没有网页范围汇总入口。
- written 仅证明 CLI 已写出，不证明模型接收、理解或完成审查。PDF 不提供整篇覆盖率；观测工具版本/哈希不能证明共享库、字体或整个执行环境固定。

## 容量观测

- `orx storage --project <id> usage` 提供项目材料、文件与交付包子集、读取回执/研究 JSON 增长、共享 SQLite/WAL/SHM 的逻辑字节及查询耗时。沿用实际会话归属，拒绝跨项目覆盖和未知会话回退。
- 目录扫描有条目/深度/时间预算，跳过链接；不完整结果明确为下界。共享数据库及交付包子集不能重复相加，项目占用不能当作执行器剩余额度。
- 查询保留生命周期保护并跳过旧缓存自动迁移。历史归档引用尚未完整登记，所有缓存 ZIP 保留；本版不新增归档删除路径，也不将观测当作配额、分页或受保护回收已完成。

## 源码与验收边界

- Git archive 固定 UTC，gzip OS 标记流式归一；Linux、macOS、Windows 对同一提交生成的 ZIP、tar.gz 和清单必须摘要一致，发布 job 还须逐字匹配 CI 保存的清单，任何失败阻止发行。已发布旧标签和附件保持不可变。
- 解析身份/范围与容量命令均有单元及真实 CLI 夹具；Linux/macOS 的真实 Poppler 外部门禁继续强制执行，Windows 未运行真实解析不能算 PDF 验收。资料为合成样本，不代表 OCR、复杂版面或科学质量验证。
- 本版仅发布源码 tar.gz、ZIP、SHA256SUMS 和 source-release.json，必须通过最终发布候选自身完整 CI。没有签名安装包，也不会自动升级生产执行器；已有 `.3` 服务器候选的备份/恢复验收不能替代本版部署验收。

进度及未实施内容见 `docs/ai-for-science/followup-execution-2026-11-06.md`；官方 .24 的全部 16 个提交及建议见 `docs/ai-for-science/upstream-v0.2.24-review-2026-11-06.md`。科学指标来源、历史归档登记/受保护回收、测试全局状态隔离和官方专项仍按独立计划推进。
