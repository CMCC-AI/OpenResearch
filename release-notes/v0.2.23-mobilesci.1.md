# MobileSci 0.2.23-mobilesci.1

本版汇总上一源码发行后的会话与科研可靠性修补，并选择性适配官方 v0.2.23 的文件显示、阅读器和运行兼容改进。真实合并祖先仍为 v0.2.19，不能按产品版本号推断已完整接入官方 v0.2.23。

## 主要改进

- 聊天文件引用正确处理编码后的 `#`、`?` 等文件名字符，拒绝 NUL 与非法编码，避免文件定位失败；保留已经实现的中文产物和材料链接处理。
- OpenAI 引用标记中的可解析 URL 显示为链接，流式输出不显示未完成标记；代码及文件提及内容保持原样。无法解析的内部引用不会冒充有效来源。
- CSV/TSV 在既有共享阅读器上支持筛选、数值排序、原始行号和虚拟行，可切换首行是否作为标题。保留 16 MiB、1000 行、100 列和单元格长度限制；排序只作用于预览，完整内容仍由原文件下载取得。Office、Notebook 和压缩包预览保持原有流程。
- macOS 可以识别 ChatGPT.app 内置 Codex；Claude 主会话与辅助调用显式设置调用方标识；Windows Git Bash 探测兼容 Git shim。
- 远端安装路径按 POSIX 规则解析，不再依赖客户端操作系统；保留产品原有 login shell、SSH 传输和二进制信任策略。
- 更新既有 macOS 构建 runner、固定最低部署目标，并对临时 DMG 创建失败进行有界重试。
- 将路由间接依赖 seroval 约束到 1.6.11，解决发布审计发现的高危反序列化问题。
- 源码发布清单包含真实上游祖先、固定回移目标和回移台账，便于核对代码与发行内容；官方自动更新仍关闭。

## 上一源码版之后的可靠性修补

- steering 持久登记、跨通道去重，以及待确认请求和新编辑草稿的跨刷新恢复。
- 固定研究计划共享材料集合，并在输入变化后约束旧结果继承；材料集合登记不等于实际阅读覆盖。
- 支持显式结束研究并保留历史，保护关联分支与续聊受理，避免结束与新工作发生竞争。
- 研究巡检使用活跃记录索引；减少聚合重复序列化，流式核验产物并限制日志读取，隔离慢工作区迁移。
- 修补专家启动失败结算、自动唤醒领取、通知恢复和同组运行告警领取的竞争；失败落盘不会错误退休专家。
- 保留落地页科研领域对照及既有 MobileSci 品牌、统一账号、材料与私人执行器边界。

## 发布内容和验证边界

通过现有 `MobileSci source release` 工作流发布源码 tar.gz、zip、SHA256SUMS 与 source-release.json；只有固定候选的完整 CI 成功后才创建产品标签与 Release。详细官方提交处理见 `docs/ai-for-science/upstream-v0.2.23-backports.md`。

本地验证与远端 CI 结果另记于回移台账。本版不包含签名桌面安装包，也不表示生产服务或存量执行器已经升级；部署仍遵循 `docs/product/runtime-and-deployment.md` 的备份、升级和恢复验收。
