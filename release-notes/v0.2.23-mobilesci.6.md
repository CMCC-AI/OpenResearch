# MobileSci 0.2.23-mobilesci.6

本版把科学指标从只读核验推进到持久来源登记，并将具体观测值关联科研声明、独立审查与交付快照。真实官方合并祖先仍为 v0.2.19，v0.2.23 为部分回移；继承 `.5` 的 v0.2.24 专项适配，不表示全量同步。官方自动更新继续关闭。

## 指标历史与来源

- `orx metrics register RUN_ID --file results/metrics.json --project PROJECT_ID` 显式新增不可覆盖的历史观察；`list RUN_ID` 按游标返回最多 50 条摘要，`show EVIDENCE_ID` 读取完整快照并核对存储摘要。既有 `inspect` 保持只读，不产生登记、实验或阅读回执。
- 沿用成功 Run、报告、冻结代码和数据身份的严格核验，记录完整序列、单位/数据划分、报告/代码/数据哈希、命令、固定资源字段、核验/登记时间及生产者版本。文件读取和哈希在写事务外完成，短事务内复核 Run；失败不留部分登记。
- 单项快照最多 4 MiB，原报告仍限制 2 MiB/64 序列/10000 点，数据最多 64 文件/64 MiB，代码归档最多 512 MiB。项目存储观察增加登记数和快照逻辑大小，不能与共享数据库物理占用重复相加。
- SQL 保护拒绝覆盖、单项删除和冲突替换。原文件或 Run 被清理后，历史登记仍可查询；项目整体删除沿用现有级联边界。登记不冻结当前文件，也不是运行时输入或科学正确性的证明。

## 声明、审查与交付

- `orx research claim --file claim.json` 接受可选 `metric: {evidenceId, name, split, step}`，精确关联登记中的一个观测值。它补充既有同项目 Run 日志选区，核对成功状态、Run/实验、命令、commit、冻结代码 SHA/字节数；不查询最新值、不换算单位、不补点。
- 规范指标引用由服务端生成并纳入声明体、证据摘要和兼容标记。新增来源或在已启用指标的研究中追加普通推测，会失效旧交付 gate；修订计划与交付要求独立审稿和引用审计，旧证据摘要不能复用。
- 研究包按登记 ID 去重保存 `scientific-metrics/<UUID>.json` 的原始序列化字节，文件 SHA-256 等于引用的快照摘要。清单与人工确认继续绑定不可变 ZIP，保留既有日志证据及 2048 文件/512 MiB 总预算，不省略超限来源。
- 网页在当前和历史声明下展示固定指标、数据划分、step、数值、单位及身份。证据页头部、工具与正文共用滚动区，窄屏可以完整查看引用卡片和展开来源。非法值明确显示错误；只读案例使用已保存引用，指标卡片不查询私人执行器。

## 验收与边界

- 新回归覆盖跨范围/身份/缺失旧元数据、失败回滚、不可覆盖、旧批准失效、重新审查及实际 ZIP 原始字节和清单；前端检查历史分组、数值/单位保留与非法数据拒绝。
- 浏览器在既有三项实际应用场景上增加静态公开案例指标的宽屏、390px、折叠导航和零私人查询场景；该投影不是原生执行器产生的科学结果。原生 Run/指标登记保持零，实际上传及两条 CLI 读取的夹具基线单独核验。
- 发行仅提供源码 tar.gz、ZIP、SHA256SUMS 与 source-release.json；冻结提交须通过独立完整发行 CI，三系统归档摘要和实际发布附件须逐项核对。旧标签及附件保持不可变，不自动部署，也不提供签名安装包。
- 运行时输入证明、数据/代码原件与执行环境封存、指标曲线和跨 Run 比较、Trackio adapter、总配额及材料/Run 生命周期仍未完成。生产切换仍需本版本自己的备份/恢复、实时活动准入及实际入口验收。
