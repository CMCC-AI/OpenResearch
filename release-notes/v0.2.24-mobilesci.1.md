# MobileSci 0.2.24-mobilesci.1

本版将选择性回移基线推进至 `v0.2.24`（真实官方合并祖先保持 `v0.2.19`，官方自动更新保持关闭），集中交付管理员供应商与模型开关配置闭环、SQLite 并发初始化与回合租约稳定性加固，以及跨代理数据目录一致性修补。

## 管理员供应商与模型开关配置

- 管理后台模型接入重构为类似 OpenCode 的“先连接供应商、再通过开关管理模型”两步流程，支持已连接供应商标签页切换、模型搜索过滤与一键启停。
- 平台新增供应商级连接（`connect-provider`）、可用模型探测（`probe-models`）与断开清理（`disconnect-provider`）接口；同一供应商或同源网关地址下切换模型开关时自动继承既有密钥，无需重复输入凭据。

## 存储并发、回合租约与跨进程文件锁

- 打开本地 SQLite 存储时先设置 `busy_timeout`，对 `journal_mode=WAL` 初始化时的 `SQLITE_BUSY` 执行有界退避重试，并将建表语句合并至同一事务内提交（适配官方 `#985`）。
- 过期回合租约清理、回合认领与数据目录迁移锁检查传入当前进程持有的活跃租约列表 `held_turn_leases`，防止进程短暂阻塞超过租约 TTL 时误中断自身正在运行的聊天回合（适配官方 `#952`）。
- `drain_queue` 仅接管由上一回合置为 `Draining` 状态的槽位，消除空队列检查时的无效租约抢占（适配官方 `#981`）。
- 新增 `FileLock` 守卫并在析构时显式调用 `unlock()`，修复多线程并发启动子进程时继承文件描述符导致的跨进程锁滞留（适配官方 `#990`）。

## 运行时环境与产物链接修复

- `set_chat_session_env` 统一将 `ORX_DATA_DIR` 固定为当前仪表盘规范化数据目录，确保 Claude Code、Codex、OpenCode、Cursor 与 Antigravity 子进程与仪表盘访问同一存储（适配官方 `#962`）。
- 短生命周期 CLI 命令在标准输出管道提前关闭时安静退出；只读查询命令在受限沙盒下支持通过 `Store::open_for_reading` 只读打开数据库（适配官方 `#962`）。
- Unix 私有运行时目录采用 `DirBuilder::mode(0o700)` 原子创建并复核已存在目录归属与权限（适配官方 `#923`）；实验源码归档固定 `core.autocrlf=false` 与 `core.eol=lf` 保持 LF 字节（适配官方 `#730`）；Markdown 产物链接兼容含裸 `%` 的合法文件名（适配官方 `#786`）。
