# MobileSci 0.2.24-mobilesci.1

本版将选择性回移基线推进至 `v0.2.24`（真实官方合并祖先保持 `v0.2.19`，官方自动更新保持关闭），在 `.7.1` 多用户稳定版基础上集中交付管理员供应商级模型配置、精选案例按对话发布与慢速下载保护、执行器插件缓存预热、SQLite/回合租约/文件锁并发加固，以及本地多用户托管一键调试环境。

## 管理员供应商与模型开关配置

- 管理后台模型接入（`/admin/opencode`）重构为类似 OpenCode 的“先连接供应商、再通过开关管理模型”两步流程，内置常见 OpenAI 兼容供应商上下文与输出上限目录，支持已连接供应商标签页切换、模型搜索过滤与一键启停（`d4a449d9`）。
- 平台新增供应商级连接（`connectProvider`）、可用模型在线探测（`probeModels`）与断开清理（`disconnectProvider`）接口；同一供应商下启用新模型时自动继承已保存凭据与请求头，密钥与私有请求头持续保持脱敏（`473c8671`、`4f271b47`）。

## 案例发布、执行器缓存与本地多用户调试

- **案例管理增强**：支持按主对话挑选成果目录与附件快照发布至精选案例（保留中间数据与材料读取快照边界），提高快照上限至 64 MiB，自动替换 PostgreSQL JSONB 不兼容的 `\u0000` 与孤立代理字符，并在只读案例副本中对缺失的工作区 `/file` 请求回退到产物预览；修复案例/历史项目缺少 `tasks` 字段时的 `TypeError`（`c9671b53`、`2b708ad2`、`84d34edf`、`bd886138`、`8ad6954a`）。
- **成果慢速下载防护**：在 tunnel 与 runner 间引入逐块流控确认，将文件响应上限统一为 128 MiB，避免慢速下载导致连接超时截断（`0e763eee`）。
- **执行器启动优化**：执行器镜像在 `/opt/opencode-npm-cache` 预热 OpenCode 插件依赖并在启动时并入 HOME 缓存，同时放宽工作目录初始化配置超时至 120 秒、收敛模型匹配上限至 30 秒，减少首次冷启动卡顿（`352f3e47`）。
- **本地多用户托管启动器**：新增 `start-hosted-local.command` / `stop-hosted-local.command` 与 `scripts/hosted-local.mjs`，支持在本机通过独立 Compose 项目（`5400` 端口）完整拉起平台 + provisioner + 私人执行器池并一键授予管理员权限；`Dockerfile.executor` 支持可选 `APT_MIRROR` 与 `NPM_REGISTRY` 参数（`c89fdda4`）。

## 存储并发、回合租约与跨进程文件锁

- 打开本地 SQLite 存储时先设置 `busy_timeout`，对 `journal_mode=WAL` 初始化时的 `SQLITE_BUSY` 执行有界退避重试，并将建表语句合并至同一事务内提交（适配官方 `#985`，`45d5c6aa`）。
- 过期回合租约清理、回合认领与数据目录迁移锁检查传入当前进程持有的活跃租约列表 `held_turn_leases`，防止进程短暂阻塞超过租约 TTL 时误中断自身正在运行的聊天回合（适配官方 `#952`，`45d5c6aa`）。
- `drain_queue` 仅接管由上一回合置为 `Draining` 状态的槽位，消除空队列检查时的无效租约抢占（适配官方 `#981`，`45d5c6aa`）。
- 新增 `FileLock` 与 `LockedAsyncFile` 守卫并在析构时显式调用 `unlock()`，同时在 `SourceFile` / `FileSource` 销毁与研究封存包流式下载结束时显式释放 `flock`，修复多线程并发 `fork` 子进程继承文件描述符导致的跨进程锁滞留（适配官方 `#990`，`45d5c6aa`、`68f41ff7`）。

## 运行时环境、文献检索与前端安全链接修复

- `set_chat_session_env` 统一将 `ORX_DATA_DIR` 固定为当前仪表盘规范化数据目录，确保 Claude Code、Codex、OpenCode、Cursor 与 Antigravity 子进程访问同一存储；短生命周期 CLI 命令在 stdout 管道提前关闭时安静退出，只读查询命令支持 `Store::open_for_reading` 降级只读打开（适配官方 `#962`，`19f75bcc`）。
- Unix 私有运行时目录采用 `DirBuilder::mode(0o700)` 原子创建并复核已存在目录归属与权限（适配官方 `#923`）；实验源码归档固定 `core.autocrlf=false` 与 `core.eol=lf` 保持 LF 字节（适配官方 `#730`）；Markdown 产物链接兼容含裸 `%` 的合法文件名（适配官方 `#786`，`19f75bcc`）。
- 将 Markdown 中 `https://` 与 `//` 外链图片转为可点击链接，禁止在产物/报告视图隐式发起第三方图片请求并消除 `<a>` 标签 `node` 属性泄漏（适配官方 `#909`，`21dced48`）。
- 支持通过 `OPENALEX_MAILTO` 与 `OPENALEX_API_KEY` 配置 OpenAlex 联系邮箱与认证请求头并移除默认共享邮箱（适配官方 `#747`）；支持读取 Claude Code 插件 `plugin.json` 声明的自定义 `skills` 目录及单技能根插件（适配官方 `#903`）；拆出 `src/local/chat/{session_env,watcher,wire}.rs` 降低单模块复杂度（`68f41ff7`）。
