# MobileSci 0.2.23-mobilesci.5

本版将工作区恢复、材料阅读范围网页、归档保留与有界回收、测试进程隔离和科学指标来源检查整合为同一源码版本。真实官方合并祖先仍为 v0.2.19，v0.2.23 为部分回移；另含 v0.2.24 的 #698/#860 测试夹具及 #872 工作区恢复适配，不代表完整接入 .24。官方自动更新继续关闭。

## 工作区与材料

- 首页和聊天侧栏共享会话恢复流程，保留目标项目的材料、研究、文件等面板；处理暖/冷入口、取消、重试、过期响应和未保存离开保护。私人空间与只读案例查询范围分开。
- 材料阅读器增加“读取范围”，按文件、会话、实际任务/计划及解析视图展示已确认输出的范围并集，保留来源/视图哈希和生产者版本。失败、pending、旧未知身份单独列出；重复读取不重复计数，PDF 仅展示单页范围。
- 有界只读接口最多两个并发、10000 条事件、512 组、2 MiB 响应；超限要求缩小查询，不返回部分汇总。网页预览、下载与其他工具读取不生成 Agent 阅读回执；written 不证明理解或审查完成。
- 案例复制整包及逐文件范围快照，并在复制结束复核内容；只读案例不回退私人执行器。窄屏按导航实际宽度布局，说明、筛选和结果共用滚动区，完整结果可滚动查看。

## 归档与指标来源

- 持久保留历史交付包登记和引用关系，提供操作员显式预览与受保护回收；历史/未知缓存不自动变为可删对象，当前输入、审批、活动运行、在途文件和恢复所需对象继续保留。
- 回收扫描提供固定截止时间、窗口绑定令牌及游标续页，每页限制扫描条目、候选数量和字节量；失败保留可重试游标，CLI 同时给出结构化结果和非零退出。没有自动删除材料、Run 或研究记录。
- `orx metrics inspect RUN_ID --file results/metrics.json --project PROJECT_ID` 核验成功结束的同项目 Run、报告、冻结代码和数据文件字节身份，保留单位、数据划分及严格递增 step。报告最多 2 MiB/10000 点，数据核验总计 64 MiB；未知字段、跨项目、越界路径或来源变化整体拒绝。
- 指标文件与 Run 的关联仍是生产者声明；检查时哈希匹配不证明运行时实际使用、科学正确性或可复现性。尚未持久登记指标证据，也未提供指标曲线、跨 Run 比较、运行时输入证明或 Trackio adapter。

## 验收与发行边界

- 六项会话/执行器环境测试及另外 31 项遥测测试改用隔离子进程，阅读范围 HTTP 回归也复用同一工具，校验真实退出标记和实际执行测试数；不放宽生产超时。官方原生夹具及本地租约准备修正保留。
- CI 使用实际应用、隔离 dev-slot、真实后端/CLI 和合成账号材料，验收工作区恢复、范围并集、案例私人接口零请求及宽窄屏；审计领域活动等于显式夹具基线，不能当作真实用户科研结果。
- macOS 的 Node/Git 源码归档使用标准 Intel runner，Rust 原生构建、测试和真实 PDF 继续保留 ARM。Linux/macOS/Windows 同提交归档摘要必须一致，发行 job 重新生成的清单仍须匹配完整 CI 的清单。
- 只发布源码 tar.gz、ZIP、SHA256SUMS 和 source-release.json；最终冻结提交必须通过自己的完整发行 CI。旧标签与资产保持不可变，不提供签名安装包，也不自动部署。
- 总配额、材料/Run 生命周期、完整科学指标证据与展示以及其他官方专项仍未闭合；生产升级另需同候选恢复、活动准入和真实入口验收，不能借用 `.4` 的部署准备结果。
