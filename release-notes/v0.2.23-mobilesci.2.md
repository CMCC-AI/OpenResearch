# MobileSci 0.2.23-mobilesci.2

修正研究交付被未引用历史日志阻塞的问题。此版基于 0.2.23-mobilesci.1，官方上游祖先及 v0.2.23 部分回移状态保持不变。

## 交付日志范围

- 当前交付只核验最新计划任务的 Run 与现有声明显式引用的 Run；不再读取未引用的旧计划或旧尝试日志。
- 当前计划继承的运行结果仍需日志；显式引用的历史日志缺失、实验日志哈希变化仍阻止交付。
- 历史运行记录、用量统计与活动保护继续保留：历史 Run 未结束或元数据缺失仍阻止交付，不会借此绕过运行保护或执行日志回收。
- 交付范围变化时原申请不能直接批准；系统保留旧决定并重新申请，用户确认当前范围后，未引用历史日志的后续变化不再改变交付哈希。

## 验证与交付

新增回归先复现旧实现的失败，再覆盖历史与当前日志、旧尝试引用、篡改检测、继承结果、元数据及活动运行保护和审批重新确认。完整验证记录见 `docs/ai-for-science/research-delivery-scope-2026-11-02.md`。

通过固定提交的完整 CI 后发布源码 tar.gz、zip、SHA256SUMS 与 source-release.json。源码清单继续包含真实上游祖先和回移目标。前端源码及 ui/dist 不变，无数据库 schema 迁移。

这是源码修补版，不包含签名安装包或生产部署。材料阅读追溯、声明撤回/版本化、科学指标和受保护容量治理仍待后续实施。
