# 托管部署的存储设置

服务器部署沿用账号服务的系统管理员权限 `platform_users.is_admin`。研究空间的 owner 不等同于系统管理员，不会因本次改动获得系统权限。

| 环境与身份 | 存储页面 |
| --- | --- |
| 本机安装与本地开发 | 保留原有目录查看和迁移行为；环境变量固定目录时仍不可修改 |
| 托管部署的普通用户、研究空间 owner | 显示「存储由服务器统一管理」，不请求或显示物理目录 |
| 单一共享研究服务的系统管理员 | 查看当前后端目录，可刷新；不提供更改目录、验证目标路径或迁移按钮 |
| 独立托管工作空间 | 显示托管说明，不将共享后端目录暴露给租户或工作空间管理员 |

账号会话和工作空间上下文返回 `storage` 能力信息。前端根据该能力选择托管或本机界面；托管子路径和云工作空间在能力不可用时仍不显示本机迁移控件。

`GET /api/platform/storage` 必须有有效的平台会话。普通用户只获得托管策略；仅配置共享科研后端且账号具有系统管理员权限时，账号服务才读取固定的 `http://127.0.0.1:4791/api/settings/data-dir`。响应仅包含托管策略、当前目录和来源，不转发浏览器 Cookie、不接受调用者指定的目标服务或文件路径，并设置超时和禁止重定向。其他 HTTP 方法返回 405。

公网原有 `/api/settings/data-dir` 和 `/mobilesci/api/settings/data-dir` 拦截继续保留，不放开原始存储接口。目录迁移通过服务器维护操作完成。无需增加环境变量或数据库迁移，也不变更已有管理员或 owner 权限。

API 错误处理将 HTML / XHTML 代理错误页转换为简洁的本地化提示，保留 HTTP 状态码，不再将 Nginx 整段源码显示在页面里。正常 JSON 错误信息及文件冲突错误保持原行为。

本次只修改代码，未部署服务器。验证包括存储权限和响应过滤、只读界面、权限失效隐藏旧目录、代理错误提示、账号集成测试及前端构建。共享目录中并行的精选案例改动影响了全量 UI 测试的三项登录路由断言，需在该功能完成后统一复验。
