# SONA 品牌与主题

SONA 是当前科研工作台的产品名称。产品导航、项目工作区、设置、引导、多语言文案、浏览器标题以及统一账号入口均使用 SONA；图标使用蓝底白色 S，与站点图标保持一致。

浅色主题使用蓝色主色 `#006eb8`、浅蓝画布 `#f4f8fc` 和选中背景 `#e4f3fc`。深色主题使用深蓝画布 `#0d1d2e`、主色 `#67c6ff`。组件沿用主题变量，因此专家团 DAG、流程卡片、导航、按钮和弹窗同步适配。成功、失败、告警等语义状态保留各自颜色。

新建项目默认位于 `~/SONA/`，已有项目不会迁移。`orx` 命令、API 路径、环境变量、数据库目录、内部查询键和上游下载地址保留兼容名称。源码中的 OpenResearch 上游说明和许可归属保留原文。

工作区不再展示上游桌面应用下载推广，避免将上游安装包误认为 SONA 发行包。SONA 的独立桌面发行需要另行配置发布和更新渠道。

验证：UI 单元测试、样式检查、多语言检查、类型检查与生产构建；统一账号静态页格式检查与已有单元测试。生产构建同时更新 `ui/dist`。
