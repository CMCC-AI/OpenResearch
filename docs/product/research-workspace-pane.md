# 科研专家团工作区面板

工作区的「科研专家团」按钮与聊天进度卡片统一打开右侧 `research` 标签，沿用文件、实验等标签的切换、关闭、宽度调整和放大行为。标签归属于当前对话，支持 URL 定位和工作区状态保存。后端 `HomeView::Research` 与前端 Pane 定义保持一致。

面板默认显示七个研究环节的纵向 DAG。环节状态来自当前计划、专家任务与人工决策；虚线表示环节顺序指引，不作为实际任务依赖。点击环节可查看参考专家、真正安排的任务、前置依赖、会话和验收产物；参考专家不会被当作已调用专家。可切换完整专家能力图或本次任务真实依赖图，使用「定位当前」与缩放控件浏览。

「查看分工与人工确认」在同一右侧面板中打开三层分工与审批页面，返回按钮回到流程图。工作区放大按钮沿用既有布局控制。聊天进度卡片不再打开另一个研究流程弹窗。

验证覆盖专家团 Pane 解析、工作区序列化与恢复、文件标签共存，以及 Rust JSON 往返。包含新 HomeView 变体的后端可持久保存专家团标签。遇到旧后端明确拒绝 research 变体时，前端仅在保存请求中剔除该标签及其位置并重试，保留文件、实验等已有标签；当前 URL 仍可打开专家团。完整标签记忆在后端更新后启用，不自动重启科研服务。
