# 精选案例：真实项目的公开研究档案

精选案例展示已经执行过的项目。点击卡片进入独立的只读详情页，不再填入研究目标，也不自动创建项目或执行模型调用。

## 管理与发布

只有账号平台的系统管理员（`platform_users.is_admin=true`）可以管理案例。科研空间 owner 与系统管理员为两个独立权限；owner 不会自动提权。管理员也不会因此获得其他用户原项目的访问权限。

管理员从首页“精选案例 → 管理案例”，或项目菜单“添加到精选案例”进入。选择自己有权访问的项目，填写标题、简介和分类，再勾选成果文件。文件可以来自项目成果目录、主仓库或某个会话工作区；公开文件名可以单独修改。

“生成待审核快照”复制这个项目在 orx 中保存的全部非空研究会话，包括归档会话、分支消息、工具输入/输出、提示和嵌套智能体记录。不是从模型供应商另行下载历史，也不能恢复原本没有保存的输出。运行中的研究、排队消息或读取期间变更的会话会阻止导入。

成果复制为独立字节副本，记录大小与 SHA-256。默认不勾选任何文件，不把原服务器文件路径作为公共下载地址。管理员在草稿详情中逐会话审核对话，预览或下载成果，确认可向所有登录用户公开后发布。对话中的文本不会自动删改或自动脱敏；发现不宜公开的内容时，不应确认发布。

草稿、未完成文件上传的案例以及未确认审核的案例不能发布。发布要求草稿版本号与审核时一致，文件上传会递增版本号，避免审核后内容变化。已发布快照不能追加文件；需要替换内容时先下架，再从整理后的项目生成新的案例快照。排序和下架操作也校验版本。

## 普通用户

普通账号登录后可以打开 `/cases`（现有服务器子路径为 `/mobilesci/cases`），查看已发布案例及 `/cases/<案例ID>` 的完整对话、时间顺序、分支关系和成果文件。无共享科研空间权限的账号从科研首页转到案例页，导航中不加载私有项目、事件流、研究偏好或远程主机配置。

公共读接口验证有效登录会话。草稿与下架案例返回 404，普通账号不能调用管理接口。原项目仍通过既有空间授权与网关鉴权访问；新建的 `catalog-session` 只供案例与页面权限判断，原 `browser-session` 的共享空间 owner 检查保留。

对话按纯文本展示，记录里的 Markdown、图片地址、HTML 和工具命令不会自动加载或执行。成果通过专用 ID 下载，响应强制为附件与 `application/octet-stream`，同时设置 sandbox CSP 和禁止缓存。文本预览只展示前 64 KB，并明确提供完整文件下载。下架后新的详情和文件请求都被拒绝；页面每 30 秒重新检查可用性。已经下载或已经被用户保存的内容不能撤回。

## 存储和接口

原始项目、对话和成果仍留在原 orx；管理员生成的案例副本进入账号平台 PostgreSQL，只有已发布状态对普通用户可见。追加迁移 `005.sql` 创建 `featured_cases` 与 `featured_case_files`，不修改已有用户、项目或密码。公开接口不额外返回来源项目 ID、发布者 ID、原目录或实时执行器元数据；对话原文里已有的路径和其他文本按管理员审核后的内容保留。

- `GET /api/platform/cases`：已发布案例列表。
- `GET /api/platform/cases/:id`：完整公开快照及成果清单。
- `GET /api/platform/cases/:id/files/:fileId`：成果字节副本。
- `/api/platform/admin/cases`：系统管理员创建和列举草稿。
- `/api/platform/admin/cases/:id`：管理员预览；DELETE 只删除草稿及其副本。
- `/api/platform/admin/cases/:id/files`：为草稿上传成果副本。
- `/api/platform/admin/cases/:id/{publish,unpublish,order}`：审核发布、下架、排序。

跨源调用仅允许已配置的账号/科研页面 origin 和有效工作空间 origin；写操作校验来源，上传完成后重新验证管理员身份。管理写操作记录审计事件，审计不记录对话、文件内容或账号凭据。

第一版限制：请求正文 16 MB、单条消息 2 MB、最多 500 个会话及 50,000 条消息；单个文件 25 MB，每个案例最多 200 个文件、总计 200 MB。超过限制会拒绝发布，不截断研究过程。案例列表最多返回 200 项。

## 验证与部署

数据库集成测试覆盖普通用户与 owner 不得发布、登录/来源校验、草稿隐藏、上传完整性与版本冲突、发布后的完整对话及附件响应、禁止修改已发布快照、下架撤销读取、管理员权限即时撤销和会话退出。前端测试覆盖真实案例路由、归档/分支保留、运行中与变化中源项目拒绝导入、超大文件流取消，以及对话 HTML/私有文件引用不执行。

部署前须应用账号迁移、更新账号平台代码，并随 Rust 二进制更新已重新生成的 `ui/dist`。不需要新增服务器 env 字段。公开副本随账号 PostgreSQL 备份一起保存；旧原项目数据和原文件不因案例下架或删除而改变。本轮实现不自动分配线上管理员角色，也不自动选择或发布线上项目。
