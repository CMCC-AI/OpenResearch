# MobileSci 宣传比较图的数据与表达约定

本说明是图表底稿，供复核和后续更新使用。公开页面与演示图片只保留必要说明，不展示绝对得分、排名、统计任务数量、时间或计算公式。

## 数据来源与选取

数据来自 ResearchClawBench 官网公开的 `data/leaderboard.json`。产品对应公开参评条目 `jiutian-DeepInsight`，展示名称使用 MobileSci。对照对象为 Open Science、Claude Code、Codex CLI 和 OpenClaw。

综合比较统一使用五个条目均有有效数值的任务交集。缺失值不补零，也不把不同任务集合的综合均值直接混用。计算每个系统在该集合的平均得分，再计算 MobileSci 均分相对各对照均分的提升。

| 对照产品 | 相对提升 |
| --- | ---: |
| Open Science | 31.0% |
| Claude Code | 36.8% |
| Codex CLI | 48.0% |
| OpenClaw | 78.5% |

## 领域图的含义

Landing Page 展示前四个领域（能源、生命科学、化学、信息科学），使用统一蓝色系区分产品并加宽柱形。网页领域图以 MobileSci 为100分基准展示相对得分，纵轴、提示和选中数值均不带百分号；这里的100不是官方绝对得分。下方综合提升继续用百分比表示提升幅度。下表保留五个领域底稿，供已交付的演示图片复核；综合提升口径不随显示领域的减少而改变。

选择能源、生命科学、化学、信息科学、神经科学五个有对比优势的领域。在同一公共任务交集中按领域取均值，每个领域分别以 MobileSci 的均值为 100%，计算其他产品相对该基准的百分比。五个领域之间不比较绝对水平；图中 100% 不是满分、通过率或任务成功率。横轴代表领域，每种颜色始终代表同一产品。

| 产品 | 能源 | 生命科学 | 化学 | 信息科学 | 神经科学 |
| --- | ---: | ---: | ---: | ---: | ---: |
| MobileSci | 100.0% | 100.0% | 100.0% | 100.0% | 100.0% |
| Open Science | 57.8% | 60.1% | 45.3% | 49.6% | 54.4% |
| Claude Code | 68.2% | 66.2% | 10.4% | 60.7% | 22.1% |
| Codex CLI | 72.3% | 67.3% | 16.7% | 67.9% | 28.6% |
| OpenClaw | 69.0% | 63.7% | 3.5% | 24.6% | 27.7% |

网页标明“各领域以 MobileSci 为100分基准，展示相对得分，越高越好”。既有演示图片采用“各领域以 MobileSci 为100%，越高越好”的表达。柱形从零起算，共用比例尺，不通过截断坐标放大差距。不把所选领域推广为所有领域均领先，也不据此声称成本更低、速度更快或单一编排机制带来确定提升。
