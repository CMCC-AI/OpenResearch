# MobileSci .7 发布计划

状态：规划中，尚未冻结发行提交、创建标签或发布附件。计划版本为 `v0.2.23-mobilesci.7`。当前 Cargo 与产品版本仍为 `.6`，准备最终候选时统一升版。本计划不触发 `release/mobilesci-*` 自动发布工作流。

## 定义与范围

将已合入、可独立验证的多用户账号、月度 Token 额度、工作台设置和模型选择界面收敛为一个可追踪版本，并为原生 CLI／执行器的统一升级建立验收门槛。

功能基线为产品提交 `e8b76904776831280ab48a11b060a753083d577e`，包含 PR #24/#25/#26。PR #26 的完整 CI [42773618181](https://github.com/CMCC-AI/OpenResearch/actions/runs/42773618181) 已通过；最终发行候选须运行自己的完整 CI，不能直接借用此结果。

| 纳入范围 | 完成标准 |
| --- | --- |
| 用户月度 Token 额度 | 注册默认每月 200 万；管理员逐用户配置；上海自然月重置、不结转；跨月在途请求结算原账期；未知用量保留预占及人工补账 |
| 凭据与账号边界 | 平台 Key 不挂入用户执行器；runner 身份绑定账号；普通用户不能修改额度；停用及过期身份拒绝调用；仅已配置前端来源可管理账号 |
| 工作台个人设置 | 个人二级菜单进入额度；账户资料及密码修改位于设置；管理员从系统管理和用户列表管理额度；旧账号页仅作为认证与跳转入口 |
| 模型选择与产品文案 | 展示当前真实可用模型并支持搜索、滚动；不以固定模型数量作为承诺；界面隐藏底层代理标识，保留运行所需集成 |
| 已合入 Rust 增量 | 列清锁外计划继承核验、输入冻结与容量预约、SQLite 依赖升级；在真实数据副本上验证升级和回退后再更换原生 CLI |

输入冻结仍是显式配置后使用的能力；冻结集合保留与项目删除限制必须如实说明，不将其宣传为完整固定数据复跑。PR #17 继续保留草稿，不纳入 `.7`。全后端输入绑定、通用读取监控、完整环境封存、指标曲线／跨 Run 比较及未选择的官方回移均不作为发布阻塞项。

## 已知边界

- 首版计量采用可信上下文加最大输出的保守预占，余额为正时仍可能不足以发起请求。不得随意调小模型真实上限；精准估算属于后续按需求优化。
- 历史已导出的供应商 Key 不受网关约束。先确认使用范围再评估专用 Key 轮换，不擅自停用可能供其他项目使用的凭据。
- 模型计量范围是平台供给的 Chat Completions 模型；自带 Key／订阅及未接入的原生协议不冒充已计量。
- 新版本不追扣历史用量，不重置现有管理员额度策略，不删除科研数据，也不要求把所有未实施项补齐。

## 下一批执行顺序

1. 完成本轮线上界面／平台对齐并归档回执，更新运行与发布台账。
2. 整理 `.7` 候选升版提交与发布说明，在普通功能分支审查；候选未准备完成前不推送 `release/mobilesci-*` 分支。
3. 完成原生 CLI／执行器副本验收，再固定发行提交并启动源码发布工作流。
4. 根据验收结果安排原生运行时生产窗口；保留 `.6`、当前平台镜像与数据库备份作为回退依据。
