# MobileSci 统一导航与布局

新建项目、论文发现、论文精读、能力中心与研究执行页共用 ProductSidebar 和 ProductHeader。保留一个左侧栏，内容分上下两部分：

- 上半部分是 MobileSci 原有菜单：新建项目、论文发现、论文精读、能力中心。
- 下半部分是 OpenResearch 原生项目和会话侧栏，保留新对话入口。项目直接展示，支持展开、置顶、项目管理、会话筛选、分组、重命名、归档和删除。项目区独立滚动。

首页与工作区共用原生 ProjectInfoCard、SessionFilterMenu 和 SessionRow；新建项目由上半部分菜单进入，新对话由项目区进入。首页的菜单使用最近项目作为上下文；无项目时引导创建项目。工作区保留原有虚拟列表与会话状态逻辑，首页按项目查询并展开完整会话；更多会话在侧栏内展开，不强制跳转到项目才能查看。

侧栏统一为 256px，顶部栏为 64px。执行页通过网格布局让侧栏贯穿整个高度，顶部位置导航贯穿聊天与右侧工作区。顶部面包屑与 MobileSci 标识支持返回科研首页；项目入口通过既有恢复逻辑恢复最近课题和右侧标签。离开页面不发送停止研究指令。

算力调度、设置、连接状态与版本以及退出登录归入左下角个人用户菜单；自定义和环境入口隐藏。点击账号卡片展开二级菜单，支持键盘导航、Escape 关闭和点击外部关闭。账号菜单保持连接组件挂载，避免打开远程连接弹窗后因菜单关闭而中断弹窗。未发送的输入、附件与文字标注在当前运行时内存中保存，返回研究页时恢复；运行时身份变化时清空，标注的 DOM Range 不保留。刷新浏览器后的草稿恢复不在本次范围内。

产品介绍页（/）仅在未登录时展示，不显示左侧栏，顶部保留 MobileSci 标识与登录按钮；有科研空间权限的账号登录后返回新建项目页，仅具备公共案例浏览权限的账号进入 `/cases`。非项目页面的窄屏导航收为左侧图标栏，可展开查看完整项目列表；研究页侧栏在窄屏可收起。

## 新建项目统一入口

`/projects` 是统一的新对话入口，承载目标输入、项目选择、多文件/ZIP 和文件夹材料选择。提交后直接在选中的项目中创建会话并发送首条消息；新项目先完成项目创建，再进入相同流程。推荐内容在首页展示，加载、空响应或失败时保留默认推荐。下方保留「继续研究」与「精选案例」，案例进入真实研究记录的只读快照。

左栏「新对话」、`/new` 命令、新对话快捷键、删除当前会话后的回退，以及无可恢复会话的项目入口，统一进入 `/projects?project=:projectId`。`/projects/:projectId/tasks/new` 仅保留兼容跳转，不再渲染独立页面；真实会话使用 `/projects/:projectId/tasks/:sessionId`。已有空会话保留会话身份和普通消息编辑器，不显示旧版欢迎页。

材料沿用共享上传流程，保留原文件和相对路径。创建会话失败时停留首页并保留输入；消息发送失败时在真实会话中保留草稿与重试能力。工作模式、模型和权限设置随首次提交传递，普通草稿恢复不会触发发送。

## 对话内工作模式

移除 ResearchModePicker 的双卡片流程介绍、示例课题和引导入口，保留右侧流程图与独立会诊能力。新建项目输入框和研究工作区输入框共用 WorkModeSwitch：按钮显示「工作模式」或「科创专家团工作模式」，点击切换，下面以一行小字比较单智能体验证与专家协作交付。

创建前的选择随研究目标和材料保存，项目确认弹窗不会重置模式。原有模式创建普通会话，专家团模式创建带研究记录的会话。创建后工作模式固定，输入框附近显示当前模式与简要说明，不能中途切换。继续已有项目时创建新的会话，历史会话保留各自模式和消息记录。

本次复用现有会话创建接口，不增加模式切换接口或后端存储。原有 build/plan、权限选项、材料输入和项目位置设置保持各自原来的逻辑。

## 隐藏配置页面

用户菜单隐藏自定义与环境，算力入口统一称「算力调度」。算力调度保留已配置的执行目标与历史，移除更多算力区域以及指向环境的设置链接。更多算力原本是页面内的区域，没有独立路由或查询参数入口。

`parseDestination` 和设置路由守卫拒绝 `/projects/:id/skills` 与 `/projects/:id/settings/environment`（含编码地址）。`safeLocation` 不接受这些页面，旧的恢复地址回落到可用研究页面。SettingsView 与程序化导航也检查隐藏配置，避免从其他内部入口绕回。登录状态检查继续覆盖研究页面；本次不改变研究执行所需的智能体技能、环境变量或现有后端 API 权限。

2026-10-16：工作模式分为“工作模式”和“科研专家团模式”两个大类，保持原有名称；专家团的四个预设子模式（系统文献综述、论文复现、实验数据分析报告、Idea 到实验方案）通过独立选择器按需指定，默认由主理人自动判断。三个单项会诊入口由四个预设流程入口替代；见[流程规范](../ai-for-science/preset-workflows.md)。

科研专家团默认自动识别意图并判断是否触发预设流程，用户不必先选具体流程。对话创建后固定大类；普通对话中的专家团入口另开同项目对话，不在原对话切换执行模式。

## 专家子对话导航

左侧项目列表只展示用户创建的独立主对话；自动派发的专家子对话通过科研专家团 DAG 或对话内的任务链接进入，不删除其历史记录。用户侧聊继续使用原有侧聊入口与标签。查看专家子对话时，左侧高亮所属主对话，顶部显示中文专家身份、当前任务与“返回主对话”。主对话与专家子对话之间切换时，保留研究级 DAG 页面、选中状态和视口；返回主对话恢复阅读位置，原先位于末尾时继续跟随最新消息。
