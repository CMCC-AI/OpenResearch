# MobileSci 品牌与主题

MobileSci 是当前科研工作台的产品名称。产品导航、项目工作区、设置、引导、多语言文案、浏览器标题以及统一账号入口均使用 MobileSci；图标使用蓝底白色 M，与站点图标保持一致。

浅色主题使用蓝色主色 `#006eb8`、浅蓝画布 `#f4f8fc` 和选中背景 `#e4f3fc`。深色主题使用深蓝画布 `#0d1d2e`、主色 `#67c6ff`。组件沿用主题变量，因此专家团 DAG、流程卡片、导航、按钮和弹窗同步适配。成功、失败、告警等语义状态保留各自颜色。

新建项目默认位于 `~/MobileSci/`，已有项目不会迁移。`orx` 命令和 OpenResearch 上游协议标识保持原有含义；产品名称、入口及部署命名统一使用 MobileSci。源码中的上游说明和许可归属保留原文。

工作区不再展示上游桌面应用下载推广，避免将上游安装包误认为 MobileSci 发行包。MobileSci 的独立桌面发行需要另行配置发布和更新渠道。

验证：UI 单元测试、样式检查、多语言检查、类型检查与生产构建；统一账号静态页格式检查与已有单元测试。生产构建同时更新 `ui/dist`。

所有产品入口与运行标识统一为 MobileSci：URL 使用 /mobilesci；一键脚本使用 *-mobilesci.command；本地状态位于 .mobilesci-run，服务器部署位于 /opt/mobilesci，Compose 项目名为 mobilesci-remote。旧名称不作为别名保留。既有部署必须先迁移数据目录及挂载再启用新配置。

既有服务器使用 `scripts/deploy/migrate-deployment.py` 一次性迁移，旧名称只通过 `--from-name` 传入。主服务器先校验更新包、检查空闲状态并备份数据库，再迁移目录、服务、卷和容器；文献服务器通过 `--mode literature --literature-image <新镜像>` 迁移专用角色和登录返回路径。失败时恢复旧部署。私密快照及停止的旧容器用于回滚，不作为兼容入口提供服务。
