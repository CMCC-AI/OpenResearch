## 里程碑 M0：既有交付源码与证据收口

**定义**：使最初选择的回移与既有扩展具备可追溯版本、可供本地验收的最新源码和真实的交付边界；结束持续追加机制的开发阶段。它是源码/证据收尾节点，不能冒充用户本地业务验收或独立生产验收。

| 已选范围与真实官方祖先/发行身份一致；未发布源能力和草稿分别列清 | .23/.24 固定台账、`.6` 来源清单、PR #15/#16/#17 状态及本表 |

| 本收尾变更在同一模拟合并提交通过完整 CI 并合入产品分支 | 本收尾 PR 的检查记录及最终合并身份；不能用历史 CI 代替 |
| 两次切换、真实回滚与暂停决定都有准确记录 | `.6` 发行证据最新段；第二次备份路径及脚本/计划摘要；保留服务器私有备份与凭据 |

达到上述标准可关闭本轮“源码与证据收尾”；若本 PR CI/合入未完成，M0 仍处于进行中。实际结果以 PR 检查与最终交付回复为准，不提前记为通过。

**下一节点 M1：用户本地验收完成**。用户启动最新产品源码并确认关键流程；出现具体故障才定向修补。独立生产验收是之后另行安排的节点，生产暂停不影响 M0 的定义，也不能以 M0 为由恢复操作。未来源码发行应固定新提交、跑自身完整发行 CI；本轮不另发 `.7`，不重打 `.6`。
