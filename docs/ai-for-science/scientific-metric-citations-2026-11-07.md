# 科学指标与研究声明绑定（2026-11-07）

本候选基于产品 `e957505b`，其中指标持久登记 `48ce6391`（PR #13）已通过完整 CI 并合入；本批继续实施最初计划中的指标来源、审查和交付关联。新代码不属于已发布 `.5`，也没有自动运行实验、授予实验权限或切换生产。

## 使用与核验含义

先用 `orx metrics register RUN_ID --file results/metrics.json --project PROJECT_ID` 保存核验结果，再在既有 `orx research claim --file claim.json` 的声明输入中补充一个精确选点：

```json
{
  "text": "验证集指定步骤的观测结果",
  "support": "experiment",
  "source": "实验日志与指标登记",
  "runId": "RUN_ID",
  "lineStart": 10,
  "lineEnd": 12,
  "metric": {
    "evidenceId": "指标登记 UUID",
    "name": "accuracy",
    "split": "validation",
    "step": 1
  }
}
```

`metric` 为可选新增输入，旧声明序列化和摘要保持原样。指标只补充实验声明，不能代替已有的同项目终态 Run、日志选区及完整日志摘要。指标登记必须关联同一成功 Run、实验、完整 commit、冻结代码 SHA/字节数及命令；指标名称、划分和 step 必须精确存在。缺少旧代码身份、跨项目/Run、不明确序列、失败 Run 或字段超限整体拒绝，不查“最新值”、不排序补点，也不把未知元数据解释为零。

服务端生成 `metricCitation`：登记 ID 和快照摘要、原报告 SHA、Run/实验、代码身份、完整选择器、单位/数值、核验/登记时间及生产者版本。客户端只能提交选择器，不能上传这些规范字段。它记录历史核验结果及生产者声明的关联，不证明运行时实际输入、指标正确性、理解或复现完成；声明自由文本与数值的科学解释仍需独立审查。

## 审查和兼容

文件读取、指标快照摘要和完整序列解析在写事务外进行。提交时重新检查 Run 的实验、状态、退出码、commit、后端描述、命令和更新时间以及固定登记身份；原件与日志仍沿用已有核验。单次声明保存失败回滚，不留下部分声明或版本。

新增规范引用纳入不可变声明体及证据摘要，并使旧交付 gate 失效；启用后新增普通推测也须失效旧 gate，不能保留旧审批状态；`metricCitationRevision` 记录全部历史引用数量。修订计划和交付准备均要求独立审稿与引用审计角色，旧验收的证据摘要不能复用。撤回/替代沿用显式修订收据，历史原声明保留。SQL 兼容保护拒绝把已启用的指标引用标记丢弃、回退或与引用数量脱节，避免旧二进制静默覆盖；旧数据不补造标记或重算原审批摘要。

## 交付与网页

当前有效声明引用的每个登记只入包一次。交付 ZIP 的 `scientific-metrics/<UUID>.json` 保存数据库登记快照的原始 UTF-8 序列化字节，文件 SHA-256 必须等于引用的 snapshotSha256；清单和审批范围同时纳入路径、摘要与规范选点，最终人工确认继续绑定不可变 ZIP。封存时重新解析登记并核对当前 Run 身份，不能通过伪造规范值或改变代码来源交付。依然受 2048 文件/512 MiB 总包预算约束，超限失败，不省略来源。

该文件保存核验时的报告内容、代码和数据字节身份，未把数据或冻结代码原件复制入包，不能等同于可独立重跑的执行环境。旧 Run/日志已被删除时，指标历史 show 仍可读，但本批实验声明和新交付继续遵守既有 Run/日志要求。

网页在当前和历史声明下展示固定指标、数据划分、step、登记值、单位和身份；不做百分比换算，不把指标与 token 用量混同。缺失/非法数值、摘要或时间显示明确错误，不造零值。只读案例仅使用已保存声明，指标卡片没有私人执行器查询或回退。动态曲线、跨 Run 比较、独立登记查询 API 及运行时输入证明仍未实现。

## 验收边界

Rust 使用明确标注的合成 Run/日志及已登记快照夹具；真实 register 文件核验路径由原 CLI 测试覆盖。新增四项定向回归检查固定选点、旧字节兼容、范围/身份/预算拒绝、提交前变化、失败回滚、旧 gate 失效、重新审查和实际 ZIP 内的原始字节/清单。前端测试检查真实组件输出、当前/历史分组、非法值拒绝和零私人查询。

浏览器新增第四个场景，使用明确的静态公开案例指标投影验证宽屏、390px 和折叠导航；它不是原生执行器生成的指标登记。CI 审计另断言原生指标登记数为零，保持实际上传/两条读取回执的既有基线。未通过最终候选自己的实际 CI 前，不把测试发现列表视为浏览器验收成功。
