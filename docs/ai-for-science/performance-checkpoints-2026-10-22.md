# 性能治理第二批：周期检查点存储隔离（2026-10-22）

基线 `22da675`。本批仅处理 OpenCode V1 流式等待循环的周期检查点；功能扩展、服务器部署和真实模型压力测试继续暂缓。

后续进展：普通消息事件的节流写入已迁移到相同有界异步路径，并补独立数据库的合成慢存储基线，见[第三批记录](performance-events-2026-10-23.md)。下文“事件驱动仍同步”描述的是本批结束时状态；即时提示卡、最终强制写入等边界继续保留。

## 实施范围

- 将原路由层 `blocking_task` 的实现移到 `src/local/blocking.rs`，API 与聊天检查点共用原有最多 8 个并发任务的执行池，不另建一套配额。permit 由实际后台任务持有，取消等待不能提前释放。
- OpenCode 的定时分支改为等待 `checkpoint_async`。SQLite 打开、提示卡状态协调、消息正文序列化和事务写入在后台执行，异步工作线程可以继续调度其他请求和计时器。每个 turn 仍逐次等待自己的检查点，不并行写多个快照；等待期间该 turn 的事件消费仍暂停，不承诺慢磁盘下自身 turn 的延迟消失。
- 沿用无变化不写、失败保留未确认快照并重试、工具内容截断、已有提示卡回执合并及分支父节点规则；最终写入仍使用现有强制 flush。
- `Store::checkpoint_chat_message` 使用 SQLite immediate 事务，将 turn/session/assistant 身份检查、活动状态检查与分支写入放在同一事务中。终态 turn、已完成消息、身份不符或消息创建时间不符时跳过写入，防止取消等待后仍运行的旧任务覆盖停止/完成内容或另一轮重试的消息。

事务检查与写入不可拆开：`spawn_blocking` 开始后无法依靠取消 await 停止，单纯把同步调用移入后台会引入迟到写覆盖终态的竞态。本批通过数据库约束处理这一边界，没有改变现有停止/完成流程。

## 回归依据

新增回归覆盖：

1. 单线程 Tokio 运行时中，让模拟慢存储等待由异步心跳释放，验证它没有占住唯一异步工作线程；干净快照不打开 Store，失败不确认快照，随后重试持久化尾部成功。
2. 后台任务已启动但仍在等待时取消检查点 future，分别完成停止落盘和正常完成落盘，再释放旧任务；终态正文、完成时间和分支父节点不被覆盖。
3. 错误 turn/session、不同创建时间及已完成消息均拒绝迟到写入；已解决审批卡的 resolved 和 approved 回执保留。
4. 取消执行池等待者后，实际任务仍占 permit，直到后台任务结束才释放，之后可重新获取。
5. 原有静默尾部、SQLite 写锁失败重试、强制最终写入和提示卡即时落盘回归继续运行。

验证通过：`cargo check --locked --all-targets`、`cargo fmt --all --check`、`cargo clippy --locked --all-targets -- -D warnings`、`git diff --check`；完整 `cargo test --locked` 退出码为 0，1200 项单元测试及 18 项集成测试通过，5 项专用测试按定义忽略。最终完整回归包含以上五项新增测试，及共享执行池使用方的既有回归。

日志保存在忽略目录 `.mobilesci-run/backport-v0.2.20/acceptance/performance-checkpoint-*.log`；最终结果以 `performance-checkpoint-full-tests.log` 和 `performance-checkpoint-clippy.log` 为准，源码及日志哈希见 `performance-checkpoint-evidence.json`。针对性首轮日志只有四项检查点测试，不能冒充最终五项新增回归的全部证据。

## 尚未完成的性能工作

- OpenCode 的事件驱动 `maybe_flush`、即时提示卡及最终强制 flush 仍同步执行；V2 的周期 projection flush 和其他适配器尚未接入本批异步路径。不能将本批记为聊天同步存储整体隔离完成。
- 快照比较、克隆、目标事件文件读取及广播编码仍在原 turn 上执行；长消息下应继续量化 CPU 和分配开销。
- 本批证明慢存储等待期间异步调度可前进及取消后的数据边界，不是并发吞吐或 p95/p99 的性能报告。下一批优先建立固定数据量的并发/慢存储基线，再迁移事件驱动写入，验证消息顺序、审批回执和最终写入。
- 未改 UI、依赖和平台服务，未重启现有本地实例或部署服务器；未声称完整跨平台 CI、磁盘写满聊天生命周期或生产压力验收通过。
