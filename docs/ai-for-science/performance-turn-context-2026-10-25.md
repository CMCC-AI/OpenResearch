# 启动上下文与准入快照的连续治理

基线为 `faccda6`，继续 TD-05，产品版本仍为 `0.2.21-mobilesci.1`。

## 本批处理范围

1. 发送前的 shell 历史、bootstrap、技能展开、研究上下文、会话材料和本轮附件上下文，移入既有 8 并发后台池。保留原有上下文组装函数、材料标识及“不代表已阅读”的约定；已准备好的输入仍跳过技能展开，但照常附加研究和材料上下文。
2. 项目 slash skill 的工作树存在检查与创建在同一后台阶段执行，不再由启动路径另外启动无界 spawn_blocking。shell 历史现在在工作树准备之后读取，其他上下文仍按原有顺序组装。工作树创建失败沿用原来的 best effort。
3. 持久准入后的会话 touch/读取移出全局 turns 锁和异步运行时线程，仍使用原连接，touch/读取失败仍采用原快照。完成后重新检查占位与 turn ID，再广播 user message、session、busy 并启动任务。touch 现在先于这些广播完成；不改变广播之间的顺序。
4. 运行中 steering 使用的工作树准备也改为同一有界池；其余 steering 存储和技能展开未整体隔离。

## 所有权与取消

新增 `reserved_store_phase`：先取得会话 cleanup 锁并验证 Reserved 的 reservation_id，再由实际 worker 持有 cleanup guard、TurnGuard 和 Store。全局 turns 锁仅用于短暂校验，不跨文件或数据库操作持有。

等待者取消不会释放正在执行阶段的占位或 cleanup 锁；worker 退出后才沿用 guard 清理。准入前只释放占位，准入后但尚未启动则尝试将本次 turn 标为 interrupted。工作返回错误也保留同一连接供清理，不遗留因提前丢连接而无法清理的 admitted turn。已经过期的占位不执行存储闭包；后续准入和启动继续保留归属校验。

Stop 需要等待正在执行的该阶段释放 cleanup 锁，不能中途强杀同步文件/SQLite/Git 工作。本批没有保证慢磁盘或 Git 操作中的即时停止，也没有新增持久化失败的自动重试保证。

## 验证与边界

新增回归覆盖单线程运行时中慢 worker 的计时器/turns 锁响应、取消后 cleanup 与占位保持、准入前后不同的中断清理、过期阶段不执行闭包，以及阶段错误后的连接保留与 interrupted 清理。现有上下文、材料、侧聊、准入和 Stop 回归随全量执行。

最终完整 Rust 回归退出 0，1253 项单元、18 项集成测试通过，11 项专用测试默认忽略；fmt、Clippy all-targets/-D warnings、diff 与上游基线检查通过。首次编译发现附件类型未实现 Clone 及 steering 共享工作树入口需要保留异步包装，已改为移动附件、拆分同步核心与有界异步包装后验证通过。最终结果与候选哈希保存在忽略目录 `.mobilesci-run/performance-turn-context/`。本批不改 UI，不需要重建 ui/dist；不调用真实模型、不运行实验、不重启开发槽、不部署服务器。没有新增端到端延迟或吞吐百分比结论，后台池排队与同步操作本身的耗时仍存在。

启动用量注册仍紧邻 Reserved → Active 的同步交接，本批没有机械增加 await，避免取消后出现未启动任务的悬空用量记录。该项需连同取消结算单独处理；设置/队列写入、附件保存、steering 其他同步工作、部分租约、Stop 历史标记及聊天磁盘满恢复也仍待治理，TD-05 不整体关闭。
