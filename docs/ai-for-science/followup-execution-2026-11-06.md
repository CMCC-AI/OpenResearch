## 本批源码归档重现性

新增回归已在旧实现复现：同一提交、同一 Node 进程版本，从 UTC 与 Asia/Shanghai 调用生成的 ZIP 不同。实现固定 Git archive 子进程 TZ=UTC，并流式将 gzip OS 标记归一为 RFC 1952 的 unknown（255），不缓存整个归档、不改变源文件内容。

本地 8 项源码归档、版本与发行证据测试通过：覆盖跨时区的全部资产/校验和一致、跨系统 gzip 标记及分段头部、损坏头拒绝、源码内容及已有输出保护。CI 新增 Linux/macOS/Windows 实际生成同一提交的归档，并比较三份 SHA256SUMS；只上传校验文件，任何系统生成失败或摘要不同都阻止整体 CI。跨主机是否闭合以该 CI 的实际结果为准，不能只凭本地模拟判定。

`.3` 的标签和已发布文件保持不可变。本改动用于后续候选，不能重写旧版本的校验和。
