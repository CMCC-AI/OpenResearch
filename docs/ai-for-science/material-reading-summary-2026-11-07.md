# 网页读取范围汇总（2026-11-07）

本批接续 `.4` 已发布的解析身份和 CLI 范围查询，实现网页只读汇总。基于工作区恢复候选 `5dfd582b`，在独立 `feat/material-reading-summary` 工作树开发；未发布、未部署。合入前需先完成依赖分支的完整 CI，再调整本批目标分支并验证最终模拟合并。

## 行为与依据

- `GET /api/materials/{id}/coverage` 复用 Store 的同一有界只读快照，支持 source/session/study，验证材料就绪和筛选对象所属项目；未知参数拒绝。最多 10000 条事件、512 组、2 MiB 响应；最多两个查询并发，取消请求后仍由阻塞任务持有许可。超限返回明确错误，不返回部分汇总；不承诺 SQL 的硬执行时间上限。
- 材料阅读器保留原件入口，增加“读取范围”：按文件、当前会话筛选，手动刷新，每页 25 组。按原件、解析视图、页码、任务及计划分别显示并集，重读不重复累计。列出失败、待确认、旧身份未知等排除原因，保留原件/视图/工具哈希和生产者版本。
- written 只说明 CLI 输出成功，不证明模型理解或审查。网页预览、下载及其他工具不生成阅读回执；PDF 只展示单页解析视图，不能推断整篇覆盖率。没有记录和查询失败均不能推断未读。
- 切换材料、筛选、执行空间或案例时立即隐藏旧结果，取消旧请求并拒绝迟到结果；错误保留重试。客户端校验来源、范围并集、解析身份、预算和响应筛选值，超过 2 MiB 停止读取。
- 案例发布复制整包和逐文件范围快照；旧执行器明确缺少路由时保留缺失，不伪造零值。已有接口查询失败则终止复制，不生成残缺快照。全部复制完成后重新核对范围内容，读取变化即拒绝；仅查询时间变化不影响复制。只读案例仅访问复制数据，不回退私人执行器；平台验证快照路径、项目、包、来源及格式。
