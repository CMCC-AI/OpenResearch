# OpenCode 批量问答闭环与性能边界（2026-10-25）

基线 `98082eb`，接续[授权与 Stop 子批](opencode-approval-backport-2026-10-25.md)，选择性回移官方 [#752](https://github.com/alphaXiv/OpenResearch/pull/752)（`3f5bac65417a42117210df2e77bf7b7e6e0fde5b`）的 OpenCode 问答部分。产品仍为 `0.2.21-mobilesci.1`，真实上游祖先 v0.2.19，整体回移保持 partial。

## 本批实现

- V1 批次逐题显示，原生 ID 编码保留 request/index，仅存 questionCount，不把完整问题数组复制到每张卡。任意顺序选择、多选、自由输入和单题跳过都按原始问题顺序聚合；未收齐不发请求，收齐后一次 reply，全部跳过则 reject，部分跳过保留对应空数组。
- 中间答案返回内部 PendingAnswers，由共享有界池成功持久化后才确认。打开/写入失败时返回错误，卡片仍可重试；不沿用“原生已收到答案，所以落库失败仅记日志”的最终回复语义。沿用已有 respond 串行门和消息写锁，不建新调度器或答案缓存。
- ResumeCtx 传入卡片所属消息 ID。V1 聚合和 V2 表单均只读取这一条助手消息，在共享 8 并发池中执行；拒绝跨会话读取，不照搬官方全会话历史扫描。Codex/Cursor 只适配测试夹具的新可选字段，没有功能回移。
- V2 保留原生字段类型转换及条件字段：未激活字段拒绝回答，当前活跃字段收齐才提交，外部确认字段不进入 payload。明确取消仍沿用前一批新旧 API；问答原生的 Step interrupted 和 dismissed 状态不再误报供应商故障，其他错误保持错误状态。循环强制 flush 改用已有异步持久化入口，未减少其写入频率或新增执行池。
- UI 复用现有卡片和全局输入框。V1 按钮为“跳过此问题”，V2 为“跳过这组问题”（原生 API 取消整个 form）；新增 skipScope 只开放已实现跳过的 OpenCode 卡片，不改变 Claude/Codex 或研究 G1–G4 审批。已跳过状态不显示旧选项/note 为成功回答；9 个语言目录同步更新。全局自由回答继续归属于第一个未答问题，未另建每卡输入框。
- 自动化和合成 UI 验收通过后，移除聊天 serve 托管配置中的 question 禁用；其余托管权限规则及独立 one-shot 路径不变。Plan exit 的自由输入 Yes 与选项 Yes 一致，显式跳过不触发退出 Plan。

## 验证与证据

新增五项 Rust 回归：V1 实际 HTTP 乱序/部分跳过/全部跳过/跨批隔离；V2 dismissed 与非问答错误区分；V2 条件字段、自由数值/文字及单消息读取（同会话历史故意含非法 JSON，不参与聚合）；中间答案真实打开/SQL 写失败、重试和后续 flush 保持；聊天配置允许原生提问。既有 Plan exit 回归补充自由输入与显式跳过断言。

新增三项 UI 渲染回归，覆盖跳过粒度、旧选择/note 不误显示、已答与无答案过期关闭的区别。`ui/tests/fixtures/question-batches.html` 使用真实 Message 组件及合成回调；浏览器验证乱序多选、跳过、自由回答、840/420px 面板和整组跳过标签。夹具自由输入只模拟已有 composer 的回调，不是登录态主副聊天或真实原生模型验收；夹具不进入发行入口。首次夹具重置复用了选择状态，已以 epoch 重挂载后复核，不将该夹具问题算作产品缺陷。

首次 Rust 定向编译因测试夹具位于另一测试模块而失败，测试移回所属模块后通过。最终日志、源码/产物哈希、合成浏览器状态和截图位于忽略目录 `.mobilesci-run/opencode-question-batches/`；初次失败记录不作为最终通过证据。

最终 `cargo test --locked` 退出 0：**1279 项单元、18 项集成通过，11 项专用测试默认忽略**。UI 全量 **423 项通过**；fmt、Clippy all-targets/-D warnings、Rust debug build、`pnpm build`（含类型/i18n）、样式、上游基线、两项产品版本测试和入口预算检查通过。ui/dist 已重建，入口为 2,950,785 raw / 900,967 gzip bytes。保留既有大 chunk、CSS highlight、capability-card-pattern.svg 和路由工具循环依赖提示，不将其写作本批消除项；这不是完整跨平台 CI 或生产发布验收。
