# 论文式报告与产物分类

科研专家团新计划默认交付一篇可独立阅读的主报告。执行规则位于
`agent-skills/orx-research-team/SKILL.md`，由 `src/local/research.rs` 的
`GUIDE` 编译嵌入，并通过 `turn_context()` 每轮注入主理人和专家会话。
具体角色提示词在同目录的 `references/as-*.md`；通用 `orx-reports`
技能也遵循专家团的主报告交接规则。

## 目录与责任

```text
<artifactRoot>/
  deliverables/
    report.md
    figures/                    # 正文需要时创建
    supplementary/              # 必要补充内容，非全部过程材料
  process/
    <task-id>/                  # 检索、证据、分析、大纲、草稿、审稿、清单
```

W4 的主入口使用 `deliverables/experiment-plan.md`。文件名由具体计划
确定，角色示例不是绕过已声明 outputs 的额外写入要求。不建立空目录，
不为同一内容生成多份 Markdown/JSON/YAML 或多个 final 文件。

| 阶段 | 责任与产物 |
| --- | --- |
| 主理人/规划 | 在计划中声明一个主报告、所需附件、任务用途、独立输出路径及最终整理责任人 |
| 写作 | 在本任务过程目录生成完整学术稿；按需登记独立证据映射 |
| 编辑 | 在自己的路径生成完整编辑稿，核对图表和引文，不覆盖作者稿 |
| 独立审稿/引用审计 | 审查同一确切版本的文稿与图表、引文；审查记录留在过程目录 |
| 归档 | 将已审查内容整理为最终报告及必要附件，核对相对链接，在过程目录保存 manifest |
| 人工确认 | 所有任务验收及归档完成后，确认当前确切文件版本；W1–W3 为 G4，W4 为 G3 |

归档只做目录、格式、链接整理，不添加新科学结论。需要实质修订时通过
版本化计划重做受影响任务并重新审查。已有计划与已验收产物保持原路径，
不自动迁移；精简读者交付不会删除原生证据、失败记录或历史文件。

## 主报告要求

- W1：题目、摘要、关键词、引言、实际检索/纳入方法、主题综合、讨论与
  研究空白、局限、结论、参考文献。详细检索流水与逐篇证据卡留在过程记录。
- W2/W3：题目、摘要、关键词、引言/相关工作、材料与方法、结果、讨论与
  局限、结论、参考文献。原文数值与本次实测分开，负结果不得隐藏。
- W4：题目、摘要、背景与问题、假设、拟采用的方法、实验与统计方案、
  评价与停止标准、风险与局限、参考文献。预期结果明确为待验证，不生成
  已完成实验的结果或结论，不新增必须的写作/审稿节点或运行权限。

文件直接从 `# 论文题目` 开始，其后进入摘要和正文；“写作前置”、详细提纲、
文献—论点映射只保存在独立过程文件中，不能放在标题前、正文或文末。
正文、图表与题注统一使用 `[1]`、`[1, 2]` 或 `[1–3]`，按文献首次出现
顺序连续编号，同一文献沿用编号。文末“参考文献”按同编号列出作者、论文
题名、发表信息和实际可得的 DOI/URL，每个引文与论文条目一一对应。
SRC/Claim ID、PDF 页码串、原论文 Reference 编号、packageId、哈希和内部
路径只保存在过程映射中，不进入正文、表格来源列、题注或文末条目。
用户提供的非论文示例使用可读名称，不为替换内部标识伪造论文条目。

正文使用连贯学术段落、统一标题层级、图表编号/题注和真实文末引文。
审批经过、专家名单、交接 YAML、任务进度和哈希不作为论文章节；技术
证据标识另存过程映射，实质不确定性仍必须在正文披露。不能编造作者、
机构、数据或引用来填满版式。用户明确指定的期刊/会议模板优先。

默认产物是 Markdown。额外 PDF/DOCX/LaTeX 仅在用户要求或任务约定时
生成并验证；LaTeX 源码遵循 `orx-paper` 的工作树与编译约定。论文式
文稿结构不构成已投稿、出版或满足某期刊录用标准的承诺。

## 生效与验收

这是 Agent 生成指令的调整，未增加后端强制目录校验或改变存储协议。
更新 Markdown 后需重编译 Rust 并替换实际 executor 才会生效，重启旧
镜像不会读取源码目录中的新提示词。前端与 W1–W4 的角色依赖、审批规则
保持原有定义，因此不需要为本次提示词更新重建 `ui/dist`。

现场验收使用有真实材料的新计划，检查：主理人声明的目录与任务所有权、
写作和编辑稿的完整性、最终报告的学术结构与引文、正文图表相对链接、
过程记录的独立存放、归档后精确版本的人工确认。真实模型的文稿质量
仍需此端到端验收，静态检查不能代替。
