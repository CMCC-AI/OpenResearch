基于产品提交 `70fe66f3`，在独立 worktree、`feat/material-reading-events` 实施。前两批完成读取字节快照与声明撤回/替代；本批提供可查询的读取事实，尚未完成声明到原文选区的引用闭环。

## 记录什么

`orx materials read` 对已封存、归属当前项目且存在的来源创建读取回执。原件仍按登记哈希验证，文本/Notebook/PDF 使用同一份已验证字节。成功输出增量携带 `readEventId`，其余读取字段保持兼容。

回执保存包 ID、SRC、相对路径、格式、登记 SHA-256、请求页/行参数、开始及记录时间、原件是否核验成功。解析成功时另存实际返回的页/行范围、行数、总行数、下一段位置、编号正文的字节数与 SHA-256，不保存整段正文。错误诊断最多 2 KiB，按 UTF-8 边界截断；诊断可能含解析器返回的信息。单条回执序列化不超过 16 KiB。

原件 SHA-256 和输出正文 SHA-256 含义不同：后者包含本次返回的行号及换行。Notebook 行号属于带原始 Cell 编号的只读视图；PDF 行号属于指定页本次提取的文本，不能当作原始 PDF 字节偏移。PDF 解析器的精确版本尚未单独记录，因此跨执行器重新提取不保证得到相同布局或正文哈希。

未登记/未知来源、跨项目和未封存材料在建立回执前拒绝，不把猜测出的标识记为真实来源。已登记来源的哈希失败、格式不支持、参数范围错误或解析失败产生失败回执，保留登记身份，且没有成功选区。文本和 Notebook 不再接受 `--page`，防止把无效页码写入来源信息；应使用 `--offset/--limit`。

## 输出确认与失败边界

| 字段 | 状态及含义 |
| --- | --- |
| `receipt.outcome=prepared` | 成功准备了本次选区，回执先于输出落库；不表示输出已送达 |
| `receipt.outcome=failed` | 验证或读取失败；`selection=null`，`outputState=notApplicable` |
| `outputState=pending` | 输出尚未确认；进程中断或确认写库失败也可能保留此状态 |
| `outputState=written` | CLI 的 write_all 和 flush 均成功；只证明写入输出流 |
| `outputState=failed` | 写入/flush 失败；可能只有部分内容写入，不能视作完整返回 |

写回执失败时不输出成功正文。输出已经写入但确认写库失败时命令失败、回执仍为 pending；不伪造输出已确认。输出状态只允许从 pending 确认一次，读取回执正文不能更新或单独删除。显式删除整个项目会级联清理回执。这是数据库内审计契约，不是对数据库管理员的外部签名防篡改机制。

`written` 不证明模型接收、理解、完整阅读、科学有效性或独立审查。空文本即使输出成功，实际返回行数仍为零。上传、list、浏览器预览、原件下载、旧版 CLI、其他原生工具读取均不在本记录中；不会回填虚构历史，也不生成阅读完成百分比。

## 会话、计划与查询

Agent 的项目从现有会话身份解析；不存在的 Agent 会话不得回退到显式 `--project`。手工终端读取须指定项目，回执的会话/研究/任务为 null，不推断为任何专家阅读。

读取开始前用一致的 SQLite 读快照解析会话、研究、任务绑定及输入范围；沿现有父/侧会话链最多 16 层寻找最近关联。子任务使用实际绑定计划版本，嵌套子会话同时保留调用会话与任务锚点会话。计划在读取期间变更时，记录保留开始时的关联；旧任务不会冒充新计划的阅读。无法解析关联时保留 null，不据此证明没有研究任务。

`inPlanInputs` 表示材料包是否属于所记录计划的固定材料集合：true/false 是已知结果，null 是未知/不适用。允许读取项目内计划外材料以供探索，但不会将它自动加入已批准输入；需要纳入计划时仍须修订计划并确认 G1。记录读取事实本身不改变 Study、声明摘要、任务状态或实验/交付授权。

```sh
orx materials read <package-id> SRC-0001 --offset 1 --limit 200
orx materials events --package <package-id> --source SRC-0001 --limit 50
orx materials events --study <study-id> --limit 50
orx materials events --session <session-id> --after <nextAfter> --limit 50
# 非 Agent 终端：
orx materials --project <project-id> events --limit 50
```

查询始终限定当前项目，支持 package/source/session/study 过滤；SRC 过滤必须同时给包 ID。每页 1–200 条，默认 50，按单调 sequence 升序，使用 nextAfter 游标而非页码；nextAfter 为 null 表示本次查询已无后续页。项目、材料包、会话、研究均有查询索引，不扫描或复制正文。它提供原始记录，不宣称已计算跨事件阅读覆盖。
