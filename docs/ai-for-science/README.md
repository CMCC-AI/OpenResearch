## 当前交付边界

当前支持本地个人版和服务器私人托管版，均可结合 Deep Literature 与统一账号。本地版研究数据留在用户电脑；托管版研究数据留在该用户的服务器执行环境。托管空间和独立执行器承担现行运行职责，普通用户无需手工配置连接器；历史团队成员和邀请方案不再作为当前授权依据。前端能力卡片会引导 Agent 工作，不代表每个科学工作流都有独立确定性执行器。

科研专家团支持自动判断及 W1–W4 预设流程，使用 Study、任务 DAG、人工决策和证据归档，复用原生会话与实验运行。旧会诊模式仅按历史数据读取。首页提供流程预览，执行中展示实际分工和进度；真实模型与浏览器闭环仍待现场验收。

文档中“现有”来自当前代码；“本轮”表示此次修补；“待建设”是设计，不是已实现承诺。官方限制带核查日期，真实调用以账户额度、响应头和供应商合同为准。不要沿用旧文档的配额数字。

## 维护规则

- 修改 API 时同步接口参数、失败行为、认证边界与契约测试。
- 改变渠道时记录供应商、用途、许可来源、调用频率与成本归属。
- 改变执行后端时更新状态机、取消语义、凭据注入和恢复流程。
- 文档不保存密钥、会话、数据库副本或生产日志。
- 每次上线记录提交 SHA、镜像摘要、迁移版本和恢复演练结果。
