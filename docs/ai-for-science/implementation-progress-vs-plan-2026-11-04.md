## 前一批网页引用选区的实现及验收

- 活跃的 DAG 主界面与嵌入面板新增“证据与来源”页；当前和历史声明分开，只有具备规范来源的声明显示“查看原文选区”。旧无来源声明不虚构链接，历史查看不会恢复有效状态。
- `GET /api/materials/{id}/{source}/citations/{event}` 从注册项目和已确认回执解析来源，检查包/SRC/项目匹配，核验原件、路径/格式、选区字节和正文哈希。复用已验证快照和 PDF 30 秒/有界输出规则，最多两个并发准备/解析，请求取消时释放资源。
- 后台准备在阻塞任务完成，解析不持有 SQLite 连接或写锁。返回 JSON 只含规范来源和选区正文，no-store/nosniff，不返回原件绝对路径。既有私人空间路由已经允许该 GET，未放宽平台权限。
- 浏览器只在展开或显式重试时请求，同内容轮询不重复解析；比对返回的所有来源身份及 UTF-8 长度/哈希，最多接收 512 KiB JSON，不回退到下载/私人执行器。关闭/切换时取消请求，旧响应不闪现，原文按纯文本展示；重试后保留本地键盘位置，不抢走用户已移开的焦点。
- 此 GET 成功或失败都不增加 Agent 阅读回执，不改材料清单、声明、研究或审批。只读案例缺少选区时明确失败，不能访问浏览者的私人实例来补数据。

最终本地检查：

- Rust 完整回归通过 1441 项单元测试和 23 项 CLI 集成测试；13 项既有忽略。本批新增一项真实 HTTP 回归，包含来源/项目隔离、pending 拒绝、并发限额、哈希变化及回执不变校验。
- UI 全部 552 项测试通过，新增 11 项，覆盖有界响应、身份/正文哈希、只读案例隔离、主入口可达、等价轮询不重读、过期请求、重试和焦点。
- 平台权限/真实 runner 定向测试 10 项通过，新增的断言确认既有策略允许该 GET 而仍阻止管理路径；平台测试格式检查通过。首次普通沙箱运行的端口监听 EPERM 已在允许回环监听的环境重跑，不将中间失败当作通过。
- Clippy 全目标零警告、Rust/Windows launcher 格式、UI 类型/样式/本地化、pnpm build、资源预算、上游基线、4 项版本/发行测试及 git diff 检查通过。ui/dist 已按最终源码重建；入口约 2.96 MB，预算检查通过。
