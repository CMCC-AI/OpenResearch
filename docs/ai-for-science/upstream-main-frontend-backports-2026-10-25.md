# 官方 main 前端修正回移与验收（2026-10-25）

本批以 `a2ed06b` 为基线，选择性回移 v0.2.21 之后的官方 main 变更：[压缩状态 #761](https://github.com/alphaXiv/OpenResearch/pull/761)（`228231a0e29b804a1079151114304e862a670704`）和[聊天虚拟化 #774](https://github.com/alphaXiv/OpenResearch/pull/774)（`05d58d07d7392ad242120e2f3c6c3d422df6c0c0`）。产品仍为 `0.2.21-mobilesci.1`、v0.2.19 真实祖先、v0.2.21 partial 回移；不把这些提交称为已发布的新版本。

> 后续批次已补 OpenCode 原生压缩冷恢复、切换模型及 Stop 回归，见[后端记录](opencode-cold-compaction-2026-10-25.md)。下文的待办与验证结果保留为本前端批次的历史边界。

## 压缩完成状态保护

压缩 HTTP 返回的是起始进度行，SSE 可能已经先完成同一消息。原先无条件 upsert 会把 completed/error 替换为 running。`compactSession` 的返回值现在携带 `onlyIfMissing`；reducer 在已有同 ID 消息时保留当前消息和分支指针，普通 SSE 更新仍可替换状态。

回归覆盖“完成 SSE → 切换分支 → 迟到 HTTP”以及“HTTP 先补行 → 后续失败 SSE”两种顺序。没有调整后端压缩、模型选择或 Stop。**#761 尚未整体回移**：OpenCode 冷启动原生会话恢复、其他 harness 与能力声明仍待后续小批次。

## 聊天虚拟化

- 恢复虚拟列表默认的同步滚动刷新，overscan 从 1 调整为 4；适配本产品单消息虚拟行，保留交互行驻留、分支顺序、全量无障碍入口和底部跟随。
- 聊天卸载时只保存测量高度、测量宽度、作用域及完成时间；最多 5000 条，按最近写入淘汰旧记录，不持有消息正文或 DOM。重访用 initialMeasurementsCache 初始化真实测量和初始偏移。
- 作用域包含工作空间和语言；宽度不符、完成时间改变、未完成的助手消息不复用测量。已交互的行在重访时重置展开状态，因此不缓存；已离开当前分支的行也不写缓存。卸载阶段一次建立 ID 索引，避免逐行查找消息。
- 不新增依赖、执行池、全局窗口布局或缓存持久化。全新聊天/从 loading 进入仍从估计高度开始，不能声称首次绘制完全无校正。

新增回归验证有效测量重访、宽度/作用域/完成时间失效、流式和展开行排除、5000 条上限，以及未实际重测的旧高度不能被标记成新宽度。开发专用夹具 `ui/tests/fixtures/transcript-performance.html` 使用真实 Transcript 和合成数据，未进入发行入口。

## 浏览器与性能口径

在现有 slot-1 Vite 上使用合成聊天，不写入项目数据库、不调用模型。夹具模拟生产的稳定底部回调、滚动状态和 ResizeObserver；首轮夹具回调不稳定导致每次采样重新置底，已在正式对照前修正。

同一夹具、每聊天 120 条不同高度消息、840/420px 两种面板宽度，每次记录 24 个 requestAnimationFrame 的 DOM 覆盖与位置采样。暂时恢复原 Transcript 后采集 `browser-controlled-before.json`，再恢复最终候选采集 `browser-controlled-after.json`；当前源码已恢复且自行重建 ui/dist。

| 操作 | 原实现 | 本批候选 | 解释 |
| --- | --- | --- | --- |
| 跳到较早消息 | 1 次空白覆盖采样，高度范围 2167px，最多挂载 4 行 | 0 次空白覆盖采样，高度范围 596px，最多挂载 8 行 | 预渲染增加挂载成本，减少该样本的临时空白；不是整站加速百分比。 |
| 首次切换另一聊天 | 无空白采样，最终底距 0 | 无空白采样，瞬时底距最大 804px，最终归零 | 冷首次测量仍有校正，不能宣称所有切换位置变化已消除。 |
| 返回已访问聊天 | 无空白采样，最终底距 0 | 无空白采样，最终底距 0 | 单元回归另验证实际测量被复用，不凭这一稳定样本夸大切换收益。 |
| 缩窄面板 | 无空白采样，最终底距 0 | 无空白采样，最终底距 0 | 旧宽度测量不能跨宽度复用，需要重新测量。 |
| 恢复宽面板 | 1 次空白覆盖采样，最终底距 0 | 同样 1 次，最终底距 0 | 属已观察的剩余边界，本批未解决，不能冒称零闪烁。 |

另验收流式追加、阅读中追加、结束生成、展开工作详情和切换重访。阅读中追加/结束的 scrollTopRange 均为 0，未强行置底；工作详情重访后从展开回到收起。证据在 `browser-measurements.json` 与 `acceptance.png`。这些是合成 DOM 帧采样，不是显示器绘制帧或真实模型吞吐基准。

开发态出现与官方 PR 已记录一致的 React 19 `flushSync was called from inside a lifecycle method` 日志，没有通过屏蔽日志隐藏它。宽度恢复与冷首次校正继续保留为已知限制。产品公开入口可加载，但本轮未登录复验真实账户、生产主副聊天或折叠侧栏；合成面板宽度验收不替代这些验证。

## 最终验证

420 项 UI 测试（含 28 项定向测试）通过，`pnpm build`、类型/i18n/样式、上游基线、两项版本回归与 Clippy all-targets/-D warnings 通过。入口为 2,949,101 raw / 900,558 gzip bytes，预算检查通过；ui/dist 已重建，保留现有大 chunk、CSS highlight 和 capability-card-pattern.svg 构建提示。

完整 `cargo test --locked` 退出 0，1266 项单元、18 项集成测试通过，11 项专用测试默认忽略。候选源码、产物、日志及浏览器证据哈希保存在忽略目录 `.mobilesci-run/ui-main-backports/`。本批不推送、不部署服务器、不重启 Rust 后端。#752、TD-05 后端锁等待、#761 冷恢复及删除/磁盘生命周期仍按既有计划排期。
