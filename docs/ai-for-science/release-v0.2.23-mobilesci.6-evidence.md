## 实施内容与影响

- 指标来源从只读 inspect 推进至显式 `register/list/show` 的不可变持久登记。每次登记保存历史核验观察，4 MiB 单条预算和有界列表；文件读取、完整解析和哈希在写事务外完成，提交时重新检查身份。影响 CLI、SQLite 历史和容量观测，不会自动运行实验。
- 实验声明可选择登记 ID、name、split、step；服务端生成固定规范引用，同时保留同项目成功 Run 和日志选区要求。引用计入声明摘要，新增/修订导致旧交付 gate 失效，重新要求独立审稿和引用审计。旧声明字节与摘要兼容，旧写入器不得丢弃新增身份。
- 交付 ZIP 去重保存 `scientific-metrics/<UUID>.json` 的原始登记字节，SHA 与声明引用一致，清单和审批范围纳入该来源；仍受 2048 文件/512 MiB 包预算约束。该快照不包含完整代码、数据及执行环境。
- 当前和历史声明展示固定值、单位、划分、step 和来源身份；非法字段明确报错，不做百分比转换。公开案例只用保存投影，无私人执行器回退。窄屏证据改为共用外层滚动，默认完整卡片及展开身份、含义可读。

契约和限制见[持久登记](scientific-metric-registry-2026-11-07.md)及[指标引用](scientific-metric-citations-2026-11-07.md)。登记证明核验时观察及生产者声明关联，不证明运行时实际消费、科学正确性或可独立复现。
