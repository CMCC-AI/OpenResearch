# 会话环境变量测试的进程隔离

## 依据与影响范围

`src/local/chat/mod.rs::session_env_tests` 原有四项测试通过模块私有 Mutex 和 EnvGuard 改写 ORX 会话环境。该锁不能约束其他模块的读取方，并行运行时可能短暂改变实验归属、可信端口或调用身份。恢复环境值只能保护测试结束后的状态，不能消除期间的竞争。

本批仅重构测试：父测试使用当前测试二进制精确重执行自身，子进程清空 CHAT_HARNESS、CHAT_SESSION、LOCAL_SESSION、UP_PORT 和 ORX_INVOCATION_CONTEXT，再执行原来的真实函数断言。环境改写只发生在单测试子进程；父进程不修改环境。父测试同时要求成功退出与实际执行一项测试，防止过滤名称漂移导致零测试假通过。生产代码和现有身份判断保持不变。

## 验证与边界

四项回归以四线程父测试运行通过；聊天模块扩大到八线程并行回归通过 205 项、5 项既有忽略。全目标 Clippy 零警告，格式检查通过。未通过的外部平台回归不计入本批证据；完整跨平台 CI 另行记录。

这是 P2 测试治理的一项具体闭合，不代表全部进程全局状态已隔离。其他测试中的环境变更、工具探测与全局缓存仍需逐项审计；保留 macOS 既有运行策略，不能凭本批移除全套串行保护。
