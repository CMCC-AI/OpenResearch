## 建议顺序与核查边界

本轮先完成材料读取一致性与字节边界 → 阅读事件/声明替代契约 → 指标来源 → 受保护回收与容量 → 按使用量接入移动端、SSH 和桌面专项。未提交前端候选单独合并验收，不与本轮后端修补混成发布成果。

本次以固定官方源码、本地提交及文档核查为依据，不是全面安全审计或生产容量测试。官方 PR 的验证不是本产品验收。实际实施与本地检查结果在材料读取记录中单独列出；本轮不把源码候选、模拟 PDF 解析器或文档核查描述为生产部署已完成。
